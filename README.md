# Органайзер коллекций

Учебный проект по разработке требований к программному обеспечению.

## Описание

«Органайзер коллекций» — приложение для ведения личных коллекций:

- книг;
- виниловых пластинок;
- фильмов;
- игр.

Пользователь может добавлять новые предметы коллекции, просматривать их, редактировать, удалять, выполнять поиск и фильтрацию по типу коллекции.

## Цель проекта

Разработать требования к приложению и представить их в виде технического задания и отдельных задач GitHub Issues.

## Документация

Основное техническое задание находится в разделе **Wiki** данного репозитория.


## Рабочий прототип (лабораторная работа №3)

В репозитории находится браузерное приложение «Органайзер коллекций».

**Функциональность:** добавление, просмотр, редактирование, удаление предметов; категории «Книги», «Винил», «Фильмы», «Игры»; поиск; фильтры; статусы «В коллекции» и «Хочу приобрести».

**Файлы:** `index.html`, `style.css`, `script.js`, `.gitignore`.

**Как запустить:** скачать репозиторий и открыть `index.html` в браузере. Установка библиотек не требуется. Данные сохраняются в `localStorage` текущего браузера.
